【选择原则】
1. 优先选择与用户场景、叙事目标、动作结构、情绪推进最匹配的模板。

3. 如果 prompt 偏模糊，要选择最能把该场景扩展成完整视频表达的模板。
4. 如果 prompt 已经包含明确动作、空间、视角或节奏，优先选择运镜逻辑最贴合者。
5. 不要随机，不要平均分配，不要为了多样性牺牲匹配度。

请从候选列表中选出唯一最佳 skill，并仅返回 JSON：
{
  "selected_index": 3,

}
